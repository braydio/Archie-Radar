# Repository Instructions

## Commit and push every change

- Commit every completed change before finishing the work session.
- Push every commit to the remote `main` branch (`origin/main`).
- Do not leave completed implementation changes only on a local or feature branch.
- Never force-push. If `main` has advanced, fetch and rebase or otherwise integrate its changes before pushing.
- Keep commits focused and exclude unrelated working-tree changes.
- After pushing, verify that `origin/main` points to the pushed commit.
